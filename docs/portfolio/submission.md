## 제출 전 체크리스트

- [x] 로그인 없이 실행 가능한 앱 배포
- [x] PC·모바일 브라우저 에뮬레이션에서 편집·템플릿 저장·복원·PNG 다운로드 확인
- [x] 공개용 목적·구조·결정·검증 요약 작성
- [ ] 공개 저장소 최종 파일·이력의 비밀값·개인 정보·권리 검수
- [ ] 최종 공개 커밋과 고정 소스 URL 확정, 새 익명 세션에서 모든 제출 URL 재확인
- [ ] 문구 또는 비율이 다른 제출용 완성 카드 3개 선정·제작
- [ ] 카드 3개 실제 재개방, 문구·비율·정상 열림·출처·이용 허가 기록
- [ ] 공개 이미지의 위치 메타데이터 검사와 최종 화면·문서 민감정보 검수
- [ ] 아래 확인 방법 4줄을 최종 앱에서 다시 확인
- [ ] AI와 사용자 판단 3줄의 당사자 확인

브라우저 검사에서 생성한 PNG는 기능 검증 산출물입니다. 카드별 제작 의도·권리·메타데이터 검사를 거친 제출용 완성 카드 3개를 대신하지 않습니다.

## 확인 방법 4줄 초안

위치: [공개 앱](https://jjal-card-studio-three.vercel.app/)의 자원 영역과 문구·템플릿·저장 도구입니다.

행동: 문구·자원을 추가해 편집 → 템플릿 저장 후 새로고침·복원 → PNG 다운로드 순서로 확인합니다.

통과 모습: 복원한 문서의 저장값이 같고 실제 PNG의 크기·내용이 카드 미리보기와 일치합니다. 공개 PC·모바일 검사에서 확인했습니다.

실패 모습: 잘못된 HEX 색상을 입력하면 반영되지 않고 기존 작업이 유지됩니다. 이 오류 보존은 로컬 실측 근거이며, 공개 URL에서 다시 실행한 항목으로 주장하지 않습니다.

이 네 줄은 실제 동작 근거에 따라 작성한 초안입니다. 공개 검사와 로컬 검사 범위를 구분하며, 최종 제출 링크와 완성 카드 묶음의 검수를 거친 뒤 확정합니다.

## AI와 사용자 판단 3줄 확인란

AI에게 맡긴 일: 편집기 코딩, 코드 검토, 검사 작성·실행, 결과 문서화를 지원했습니다.

본인 판단: 사용자는 다크 모드·코발트 제외, 중복 도구 제거, 정규 도형과 독립 가로·세로 조절, 비공개 원본에서 공개본으로만 동기화하는 방식을 결정했습니다.

AI 제안을 따르지 않은 일: 사용자는 불필요한 설명 문구, 자원과 중복되는 이미지 탭, 화면에서 조작할 수 있는 요소·배치 섹션을 삭제하도록 지시했습니다.

이 세 줄은 실제 수행·사용자 승인 기록에 근거한 초안입니다. 최종 제출 당사자가 내용과 자신의 역할을 확인한 뒤 확정합니다.

## 공개 범위

포트폴리오에는 구현 소스와 필요한 라이선스, 선별한 설명과 검증 요약을 포함합니다. 전체 대화·과제 원문·개인 로컬 경로·사용자 원본·인증 정보·원시 로그·배포 내부 식별자는 포함하지 않습니다. 공개된 파일과 링크 자체를 최종 검사하며, 요약 문서가 있다는 이유로 공개 안전성을 자동 판정하지 않습니다.
